# React Native Debug Exercise

An intentional meta teaching exercise for practicing bug hunting in React Native applications.

## About This Project

This repository contains a React Native/Expo project with **intentionally planted silent bugs** added by another AI agent. The goal is to practice debugging skills by finding and fixing these issues.

## Tech Stack

- Expo
- React Native
- TypeScript
- Tailwind CSS / NativeWind
- Appwrite

## Getting Started

```bash
npm install
npx expo start
```

## Environment Setup

Create a `.env` file with:

```
EXPO_PUBLIC_MOVIE_API_KEY=
EXPO_PUBLIC_APPWRITE_PROJECT_ID=
EXPO_PUBLIC_APPWRITE_DATABASE_ID=
EXPO_PUBLIC_APPWRITE_COLLECTION_ID=
```

## Purpose

This is a learning tool. The bugs are subtle and designed to simulate real-world issues you might encounter in production code. Happy debugging!
